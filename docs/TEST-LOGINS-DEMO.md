# Demo Login Credentials

Generated by the per-module dev/demo seeders in `database/seeders/` (NOT
part of `DatabaseSeeder`'s default run). Run the relevant seeders manually,
e.g.:

```
php artisan db:seed --class=CampusSeeder
php artisan db:seed --class=StaffSeeder
php artisan db:seed --class=StudentSeeder
php artisan db:seed --class=GuardianSeeder
php artisan db:seed --class=StudentGuardianSeeder
php artisan db:seed --class=TestLoginFixturesSeeder
```

## Guardians (`GuardianSeeder`)

Guardian accounts are generated per sibling family with emails of the form
`father.<familyname><n>@guardian.com` / `mother.<familyname><n>@guardian.com`
(password `123456`). Exact emails depend on the random names generated by
`StudentSeeder`/`GuardianSeeder` — check the `guardians` → `users` tables for
the current run, or use the fixed fixture below.
